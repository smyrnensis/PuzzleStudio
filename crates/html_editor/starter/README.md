# PuzzleStudio executable examples

Each puzzle file is a small, independent project about one authoring theme.
Open a file, preview it, then make the change suggested by its `TRY` comment.

1. `01-basic.puzzle` — rules, collision, winning, sprites, and levels
2. `02-scenes-and-theme.puzzle` — title flow, layout, and presentation colors
3. `03-sound.puzzle` — movement sounds, clear sounds, and scene music
4. `04-animation.puzzle` — sprite frames, directional sprites, and movement tween
5. `05-tags-marks-and-routines.puzzle` — reusable variants and staged rules
6. `06-3d.puzzle3` — a grid puzzle with depth and a camera
7. `07-meta-level.puzzle` — one puzzle used to select levels in another puzzle

The files do not import one another. Copy or download any one of them as a
starting point for a new project.
