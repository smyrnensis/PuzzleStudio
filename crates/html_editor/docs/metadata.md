# Metadata
Put display metadata near the top of the file.

```puzzle
title = "Sokoban"
subtitle = "A compact pushing puzzle"
author = "Puzzle Author"
homepage = "https://example.com"
```

`title` is the game name. `subtitle`, `author`, and `homepage` are optional.

Metadata is a value, not a component kind. Display it with a text role such as
`heading title`, `subheading subtitle`, or `caption author`.
