# Use Lucide SVG Icons

Use an icon from Lucide instead of drawing SVG path data by hand.

Select the Lucide icon whose established meaning best matches the UI action, then obtain its SVG from Lucide and integrate it in the form required by the existing codebase.

Do not invent, manually draw, or approximate an SVG icon. If Lucide has no suitable icon, stop and report that explicitly rather than creating a custom SVG.
