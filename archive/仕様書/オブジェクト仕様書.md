
# オブジェクト定義JSON仕様書

## 1. 概要

本仕様書は、ゲームに登場するすべての**オブジェクト**の「設計図」を定義するJSONファイルのフォーマットを定めます。ここで定義された内容は、ゲーム全体で共通のマスターデータとして機能します。ルールシステムやレベルデータは、この定義を参照してオブジェクトを扱います。

## 2. 基本構造

ルート要素は`objectDefinitions`キーを持つ単一のオブジェクトで、その値はオブジェクト定義の配列です。

```json
{
	"objectDefinitions": {
		"Player": {
		    "layerId": 1,
		    "properties": ["Movable", "PlayerControlled"],
		    "tags": {
				"directions": ["up", "down", "left", "right"],
			},
		    "sprite": "res://sprites/player.png"
		},
	    "Box": {
			"layerId": 1,
		    "properties": ["Movable", "Falling", "Solid"],
		    "tags": {
		        "state": ["on_goal"],
	        },
	        "sprite": "res://sprites/box.png"
	    },
	}
}
```

## 3. オブジェクト定義のフィールド

| フィールド | 型 | 必須 | 説明 |
| :--- | :--- | :--- | :--- |
| `name` | String | ○ | オブジェクトの一意な名称。ルールやレベルデータから参照されます。 |
| `layerId` | Integer | ○ | オブジェクトが所属するレイヤーのID。描画順序や衝突判定のレイヤーと関連付けられます。 |
| `properties` | Array | × | オブジェクトが持つ特性のリスト（文字列の配列）。ルール内で`@`を用いて参照されます (例: `@Movable`)。 |
| `tags` | Object | × | オブジェクトの状態を表現するタグの定義。キー（タググループ名）と値（定義オブジェクト）のペアで構成します。 |
| `sprite` | String | × | Godotエンジン内で使用するスプライトのリソースパス。 |

# ObjectDB (ヘルパーモジュール) 仕様

`ObjectDB`は、起動時に上記の`object_definitions.json`を読み込み、オブジェクトに関する情報を提供するシングルトン（または静的クラス）です。これにより、ゲームのどこからでもオブジェクトの定義情報へ安全にアクセスできます。

## 1. 主な機能

  - **定義の読み込み**: ゲーム開始時にJSONファイルをパースし、全てのオブジェクト定義をメモリ上に展開します。
  - **情報提供**: オブジェクト名やインスタンス文字列から、プロパティ、レイヤーIDなどの定義情報を返します。
  - **インスタンス生成**: 正しいフォーマットのオブジェクトインスタンス文字列を生成します。

## 2. 提供する関数 (API)

### `get_properties(object_name: String) -> Array`

指定された名前のオブジェクトが持つプロパティのリストを取得します。

  - **例**: `ObjectDB.get_properties("Player")` → `["Movable", "PlayerControlled"]`

### `get_layer_id(object_name: String) -> int`

指定された名前のオブジェクトが所属するレイヤーIDを取得します。

  - **例**: `ObjectDB.get_layer_id("Goal")` → `0`

### `get_defined_tags(object_name: String) -> Dictionary`

指定されたオブジェクトに定義されているタググループと、その設定（取りうる値、デフォルト値）を取得します。

  - **例**: `ObjectDB.get_defined_tags("Player")` → `{ "direction": { "values": [...], "default": "down" } }`

### `create_instance_string(object_name: String, tags: Dictionary = {}) -> String`

オブジェクト名とタグ情報から、`GameState`で使われるインスタンス文字列を生成します。

  - **振る舞い**:

      - 指定されなかったタググループには、定義された`default`値が自動で適用されます。
      - `default`が`null`のタグは、明示的に指定されない限りインスタンス文字列に含まれません。

  - **例**:

      - `ObjectDB.create_instance_string("Player")` → `"Player:down"`
      - `ObjectDB.create_instance_string("Player", {"direction": "right"})` → `"Player:right"`
      - `ObjectDB.create_instance_string("Box")` → `"Box"`
      - `ObjectDB.create_instance_string("Box", {"state": "on_goal"})` → `"Box:on_goal"`

### `parse_instance_string(instance_string: String) -> Dictionary`

インスタンス文字列を解析し、名前と適用されているタグの辞書を返します。

  - **例**:
      - `ObjectDB.parse_instance_string("Player:right")` → `{ "name": "Player", "tags": { "direction": "right" } }`
      - `ObjectDB.parse_instance_string("Box:on_goal")` → `{ "name": "Box", "tags": { "state": "on_goal" } }`
