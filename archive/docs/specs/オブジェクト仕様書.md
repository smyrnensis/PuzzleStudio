# オブジェクト定義仕様書

> 詳細な型定義は `docs/フレームワーク計画.md` セクション 5.3 を参照。
> JSON スキーマは `docs/フレームワーク計画.md` セクション 6.1 を参照。

---

## 1. 概要

本仕様書は、ゲームに登場するすべての **オブジェクト** の「設計図」を定義する JSON フォーマットを定める。ここで定義された内容は、ゲーム全体で共通のマスターデータとして機能する。ルールシステムやレベルデータは、この定義を参照してオブジェクトを扱う。

---

## 2. 基本構造

オブジェクト定義は `GameData.objects` 内の配列要素として定義される。各要素は `ObjectDefinition` 型に準拠する。

```typescript
interface ObjectDefinition {
  readonly name: string;
  readonly layerId: number;
  readonly properties: readonly string[];
  readonly tags: Readonly<Record<string, readonly string[]>>;
  readonly defaultTags?: readonly string[];
  readonly sprite?: {
    readonly color?: string;
    readonly colorByTag?: Readonly<Record<string, string>>;
  };
}
```

**JSON 例:**

```json
{
  "objects": [
    {
      "name": "Player",
      "layerId": 1,
      "properties": ["Movable", "PlayerControlled"],
      "tags": {
        "direction": ["up", "down", "left", "right"]
      },
      "defaultTags": ["down"],
      "sprite": {
        "color": "#4488ff"
      }
    },
    {
      "name": "Box",
      "layerId": 1,
      "properties": ["Movable", "Pushable", "Solid"],
      "tags": {},
      "sprite": {
        "color": "#cc8833"
      }
    },
    {
      "name": "Wall",
      "layerId": 1,
      "properties": ["Solid"],
      "tags": {},
      "sprite": { "color": "#404040" }
    },
    {
      "name": "Goal",
      "layerId": 0,
      "properties": [],
      "tags": {},
      "sprite": { "color": "#ff6666" }
    },
    {
      "name": "Floor",
      "layerId": 0,
      "properties": [],
      "tags": {},
      "sprite": { "color": "#e8e8e8" }
    }
  ]
}
```

## 3. フィールド詳細

| フィールド | 型 | 必須 | 説明 |
|:---|:---|:---|:---|
| `name` | `string` | ○ | オブジェクトの一意な名称。ルールやレベルデータから参照される。 |
| `layerId` | `number` | ○ | 描画レイヤー ID。数値が大きいほど手前に描画される。0: 背景（Floor, Goal 等）、1: オブジェクト（Player, Wall, Box 等）。 |
| `properties` | `string[]` | ○ | オブジェクトが持つ抽象特性のリスト。ルール内で `@` プレフィックスで参照される（例: `@Movable`）。 |
| `tags` | `Record<string, string[]>` | ○ | タグカテゴリと取りうる値の定義。キー: カテゴリ名、値: 有効値の配列。例: `{ "direction": ["up", "down", "left", "right"] }`。 |
| `defaultTags` | `string[]` | × | デフォルトタグ。レベルデータで `"Player"` と書いたとき、自動付与されるタグ。例: `["down"]` → `"Player:down"` として初期化。 |
| `sprite` | `object` | × | 描画設定。レンダラーが参照し、エンジンは無視する。 |
| `sprite.color` | `string` | × | 単色表示時の CSS カラー文字列。例: `"#4488ff"`。 |
| `sprite.colorByTag` | `Record<string, string>` | × | タグごとの色バリエーション。例: `{ "on_goal": "#88cc33" }`。 |

## 4. プロパティによる抽象化

個別のオブジェクト名ではなく、プロパティでルールを記述できる：

| プロパティ例 | 用途 |
|:---|:---|
| `@Movable` | 移動可能なすべてのオブジェクト |
| `@Solid` | 衝突判定を持つすべてのオブジェクト |
| `@Falling` | 重力の影響を受けるすべてのオブジェクト |
| `@PlayerControlled` | プレイヤーが操作するオブジェクト |

新しいオブジェクトを追加して適切なプロパティを設定すれば、既存のルールを変更する必要がない。

## 5. タグシステム

タグは 1 つのオブジェクトのバリエーションを表現する。`"Name:tag1:tag2"` 形式の文字列でインスタンスを表す。

**例:**
- `"Player:right"` — 右を向いたプレイヤー
- `"Box:on_goal"` — ゴール上のボックス
- `"Gate:open"` — 開いたゲート

### デフォルトタグ

`defaultTags` を設定すると、レベルデータで名前だけ指定した場合に自動でタグが付与される。

```json
{
  "name": "Player",
  "tags": { "direction": ["up", "down", "left", "right"] },
  "defaultTags": ["down"]
}
```

レベルの legend で `"P": ["Player"]` と書くと、実際には `"Player:down"` として初期化される。

## 7. ObjectDB（ヘルパーモジュール）

`ObjectDB` は、オブジェクト定義の配列を受け取り、オブジェクトに関する情報を提供するクラスである。

### 主な機能

- **定義の管理**: コンストラクタで `ObjectDefinition[]` を受け取り、名前→定義の Map を構築
- **情報提供**: オブジェクト名からプロパティ、レイヤーID 等の定義情報を返す
- **プロパティ逆引き**: プロパティ名から該当する全オブジェクト名を返す
- **パターン解決**: `@Movable` → `["Player", "Box"]` のようにプロパティ指定を展開

### 主要 API

```typescript
class ObjectDB {
  constructor(definitions: readonly ObjectDefinition[]);
  getDefinition(name: string): ObjectDefinition;
  getObjectsByProperty(propertyName: string): readonly string[];
  hasProperty(objectName: string, propertyName: string): boolean;
  resolvePattern(pattern: string): readonly string[];
  getAllDefinitions(): readonly ObjectDefinition[];
}
```

### オブジェクト文字列ユーティリティ

オブジェクトインスタンス文字列（`"Name:tag1:tag2"`）の操作は `utils/object-string.ts` モジュールが担当する。

```typescript
parseObjectString("Player:right")     // → { name: "Player", tags: ["right"] }
buildObjectString("Player", ["right"]) // → "Player:right"
getObjectName("Player:right")          // → "Player"
getObjectTags("Player:right")          // → ["right"]
matchObjectPattern("Player:red", "Player:$color", {})
                                       // → { "$color": "red" }
applyBindings("Box:$color", { "$color": "red" })
                                       // → "Box:red"
```

> 詳細な API は `docs/フレームワーク計画.md` セクション 7.1, 7.4 を参照。
